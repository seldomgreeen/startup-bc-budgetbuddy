# Release notes

## v1.0 — 2026-11-13 (simulated course schedule)

### Added

- Find large expenses at or above a chosen positive dollar threshold,
  without including income.
- See signed dollar totals for each transaction category, with refunds
  offsetting spending and empty accounts handled safely.
- Average saved balance history to one decimal place, including an empty
  history. This report helper was provided in the course starter.
- Automated checks for thresholds, category totals, average balances, and
  empty inputs.

### Changed

- Updated the product guide with current run commands and working examples.
- Documented the solo founder, review workflow, and one-minute demo plan.

The new reports are Python helpers; the terminal menu keeps its existing
options. The separate seeded-debugging branches contain the Lesson 10 and
11 practice fixes and are not merged into this release.
